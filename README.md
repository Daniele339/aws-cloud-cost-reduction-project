# Relatório de Implementação AWS

Projeto desenvolvido como desafio prático com foco em implementação de serviços AWS visando redução de custos operacionais em uma empresa do ramo farmacêutico.

## Serviços utilizados
- Amazon S3
- Amazon EC2
- Amazon RDS

## Objetivos
- Redução de custos
- Escalabilidade
- Segurança de dados
- Modernização da infraestrutura
